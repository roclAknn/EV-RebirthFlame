# EV-RebirthFlame
GitHub Pages -> https://roclaknn.github.io/EV-RebirthFlame/index.html

#### 概要
転生スコアごとに転生の炎がどのくらい必要かを計算・出力します。<br>

#### 使い方
1. 武器/防具（武器以外）を選択<br>
2. 装備と目標に合わせ、その他の設定を入力<br>
3. 転生スコアの基準値をステータスごとに入力<br>
4. 出力ボタンを押すと転生の炎消費数を計算した表が2列出力されます<br>
5. 列表ごとに転生の炎と装備レベルを変更してください<br>
<pre>
一般的にはメインステータスに1を入力し
その他のステータスはメインステータスを基準として値を決めます
適切な利用には転生の炎と転生スコアの知識が必要です
</pre>
#### 各項目の詳細
・出力ボーダー：出力スコアの最低値を入力。小さいほど計算・表出力に時間がかかります<br>
・ボスボーナス：ボス報酬装備など、転生が4種固定で高い数値が付与されるものならON<br>
・武器AMA簡易版(ON)：武器攻撃力転生RANKを最優先し、他転生をスコアとして使用します（推奨）<br>
・武器AMA簡易版(OFF)：攻撃力転生を含め、全オプションをスコアとして使用します。武器の未強化攻撃力/魔力が必要です<br>

#### 動作に関して
・攻撃力、魔力は職業（装備）に適した方を入力してください<br>
・0スコアが少ない、出力ボーダーが低い場合、処理に時間がかかります<br>
・201レベル以上は250レベル装備として扱います<br>

#### 未対応の装備
・一部特殊な装備。主要な装備ではない、または確率が不明なため対応していません<br>
・低レベル装備には設定されないオプションがあります<br>
・未実装、未確認の装備レベルについては参考値です<br>

#### ラバストーン転生の炎について
・古代石板のレプリカ（霧島トーテム）専用の転生の炎です<br>
・装備タイプ：防具、ボスボーナス：オフ、レベル：200で出力してください<br>
・T1:65% T2:25% T3:12% T4:3% T5:0% で計算します<br>
・55個（オプション数220）からの推測のためかなり不正確<br>
・T5は未確認のため0%<br>

出力結果には誤差、間違い、誤解が含まれている可能性があります<br>
出力結果について公式に問い合わせることなどは絶対にしないでください
